# ITL-1061 re-run cost investigation plan

> **For agentic workers:** investigation only. No change under `src/` or `tests/`. Scripts go
> under `superpowers/specs/itl-1061/`, the report goes in `superpowers/specs/2026-11-13-itl-1061-rerun-cost.md`.

**Goal:** Pinpoint, with counters and file:line references, where a second run of an unchanged
pipeline does work again, measured against the developer's model (each node holds a timestamped
in-memory cache; a re-run with no newer upstream is instantaneous).

**Architecture:** One instrumentation module (`counters.py`) monkeypatches the library at run time
and counts calls per node. One driver (`rerun_counts.py`) builds a workshop-shaped pipeline (two
`ArrowTableSource`s of a few thousand rows, drop_nulls, group_by, map_tags, join, two function pods)
and runs it through each path twice, printing a table of counts per run.

**Tech stack:** `uv run python`, pyarrow, orcapod at `origin/main` (97263e5b); optionally PR #355
(963310fb) in a scratch worktree.

**Constraints:** one python process at a time, small inputs, no test suites, no live Spiral.
