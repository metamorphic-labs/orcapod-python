### Changed

- `PipelineJob.load` raises `ValueError` when the file's database or result database is a
  connector database (SQLite, PostgreSQL, SpiralDB) and it is not given, naming each binding
  and the argument to pass (`database=`, `result_database=`). A connector is never rebuilt
  from a saved file. It used to log `Unknown database type` and load a job that could read
  nothing. (ITL-1391)

### Fixed

- When a saved database or result database cannot be rebuilt, saving the loaded job
  preserves the original configuration while that slot remains unbound. If you later
  bind a database to that slot, saving writes the newly bound database's configuration.
  (ITL-1391)
- The warnings about a saved source, database or result database that could not be rebuilt
  name the slot, the kind and the type of the error, and no longer hold the exception text.
  (ITL-1391)
