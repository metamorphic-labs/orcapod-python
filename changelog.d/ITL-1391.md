### Changed

- `PipelineJob.load` raises `ValueError` when the file's database or result database is a
  connector database (SQLite, PostgreSQL, SpiralDB) and it is not given, naming each binding
  and the argument to pass (`database=`, `result_database=`). A connector is never rebuilt
  from a saved file. It used to log `Unknown database type` and load a job that could read
  nothing. (ITL-1391)

### Fixed

- Saving a loaded job whose database could not be rebuilt writes the saved database
  configuration back as it was, instead of `null`. (ITL-1391)
- The warnings about a saved database or result database that could not be rebuilt name the
  slot, the kind of database and the type of the error, never the error's text, which could
  hold a saved path, URI or storage option and a credential in it. (ITL-1391)
