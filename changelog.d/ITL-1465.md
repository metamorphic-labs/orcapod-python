### Breaking changes and migration

- A `Condition`, including an empty one, raises `TypeError` in Python truth tests.
  Use `condition.is_empty` to check for no requirements. Pass separate conditions
  to `filter()` or separate equality keywords to `where()`, or combine parenthesized
  comparisons with `&`, `|` and `~`. Use `col("t").between(a, b)` for an inclusive
  range. (ITL-1465)

### Fixed

- Chained comparisons such as `1 <= col("t") <= 5` now raise instead of silently
  discarding the first bound. Python `and`, `or` and `not` also raise when used on a
  condition, with guidance on how to write the expression. (ITL-1465)
