### Fixed

- **A function node keeps a stored row's tag types in a later session.** When a node's
  results are ephemeral and a later session no longer has them, the node rebuilt the
  stored rows' tags from Python values: an `int8` or `float32` tag came back as a 64-bit
  type (another tag hash), and a struct tag could not be read. It now builds them from the
  stored Arrow rows. The node computes such rows again before showing or storing anything,
  so no presented row, stored row or hash changes. (ITL-1298)
