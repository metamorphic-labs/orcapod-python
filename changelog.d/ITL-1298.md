### Fixed

- **A function node keeps a stored row's tag types in a later session.** When a node's
  results are ephemeral and a later session no longer has them, the node rebuilt the
  stored rows' tags from Python values: an `int8` or `float32` tag came back as a 64-bit
  type (another tag hash), and a struct tag could not be read. It now builds them from the
  stored Arrow rows. Runs, iteration, the preview and what is stored are unchanged: the node
  computes such rows again before showing or storing them. What changes is the tag
  `get_cached_results` returns for such a row (with `EmptyData`): it now has the stored
  types, the first session's tag hash and no storage-only data-tag mark. (ITL-1298)
