### Breaking changes and migration

- File hashing now accepts only `sha256`. The `hash_path` mode and all other
  algorithms have been removed. Remove other algorithm settings from data context
  files or set them to `sha256`. Drop the `--algorithm` option from `warm-cache`
  commands and the `algorithm` argument from `populate_hash_cache` calls.

### Changed

- Removed the `xxhash` runtime dependency. Existing file hash caches retain their
  layout and historical rows. Reads for other algorithms miss and writes raise an
  error. SHA-256 digests and their `sha256` label are unchanged.
