### Added

- `SpiralDBTableSource.where(mapping=None, /, **columns)` returns a new source on the same
  table that reads only the rows in which every named column equals its value. It is a
  restriction, not an operator: the new source has the same `source_id`, `content_hash`,
  `pipeline_hash`, schema, system-tag columns and record IDs as the unrestricted source, and
  adds no node to a pipeline. Its conditions are added to those given with `where=`
  (one mechanism, applied in the SpiralDB scan); a conflicting value for a column is refused.
  Other source kinds do not have `where()` yet. A pipeline holds one source per identity,
  so one table read with two different restrictions in one pipeline raises `ValueError`.
  A `CachedSource` (or `source.cached(...)`) over a restricted source raises `ValueError`:
  a cache is kept under the table's identity, which a restriction is not part of. So does
  an operator node that caches (`CacheMode.LOG` or `CacheMode.REPLAY`) when a source feeding
  it is restricted, whichever is set first: when the cache mode is set, when `bind` binds the
  source, or when a run starts, before anything is read or written. `CacheMode.OFF` and
  function nodes are not concerned.
- `orcapod.types.Condition`: equality conditions on named columns, all of which must hold.
  `Condition.of(mapping=None, /, **columns)` builds one from the arguments `where()` takes;
  `combined` adds two and refuses a column required to equal two values; two conditions are
  equal when they require the same columns to equal the same values, in any order (values of
  different types differ; `0.0` equals `-0.0` and NaN equals NaN); `text()` / `str` show it.
  It enters no hash. `where()` and `where=` accept a `Condition` as well as a mapping.
- `RunSummary.restrictions` (slot to `Condition`), `RunSummary.limits` (slot to limit) and
  `RunSummary.restricted_source_ids` (slot to source id): each restricted source of a run, by
  slot; shown in the summary.
- `RestrictedAggregationWarning`: one per job run when a restricted source feeds a
  `GroupBy`, `Batch` or `MergeJoin`.

### Changed

- `SpiralDBTableSource(where=...)` checks each value against its column: the value must be
  exactly of the column's Python type and fit its Arrow type (no conversion: a NumPy scalar
  or a date string is refused with `TypeError`), and `None` is refused with `ValueError`.
