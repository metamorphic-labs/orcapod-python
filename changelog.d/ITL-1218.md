### Added

- `SpiralDBTableSource.where(mapping=None, /, **columns)` returns a new source on the same
  table that reads only the rows in which every named column equals its value. It is a
  restriction, not an operator: the new source has the same `source_id`, `content_hash`,
  `pipeline_hash`, schema, system-tag columns and record IDs as the unrestricted source, and
  adds no node to a pipeline. Its conditions are added to those given with `where=`
  (one mechanism, applied in the SpiralDB scan); a conflicting value for a column is refused.
  Other source kinds do not have `where()` yet.
- `RunSummary.restrictions`: each restricted source of a run, by slot, with its source id and
  its `where` conditions and `limit`; shown in the summary.
- `RestrictedAggregationWarning`: one per job run when a restricted source feeds a
  `GroupBy`, `Batch` or `MergeJoin`.

### Changed

- `SpiralDBTableSource(where=...)` checks each value against its column: the value must be
  exactly of the column's Python type and fit its Arrow type (no conversion: a NumPy scalar
  or a date string is refused with `TypeError`), and `None` is refused with `ValueError`.
