### Breaking changes and migration

- Orcapod uses full hash digests in system-tag column names and logical table
  paths. Remove `system_tag_n_char`, `schema_n_char`, and `path_n_char` from your
  hashing configuration. Programmatic configs reject these fields, and pipeline saves
  omit them. Config files and saved pipelines that specify a value for a removed
  setting raise an error naming it. Older saved pipelines may contain `null` for
  unset settings and still load. Rebuild any stores written with shortened
  system-tag names using the full digests. `ContentHash.to_hex(char_count=...)`
  still supports shortening a digest for display.
