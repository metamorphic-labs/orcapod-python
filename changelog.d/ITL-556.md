### Breaking changes and migration

- Orcapod uses full hash digests in stored column names and table paths. Remove
  `system_tag_n_char`, `schema_n_char`, and `path_n_char` from your hashing
  configuration. Configs and saved pipelines that specify a value for a removed
  setting raise an error naming it. Older saved pipelines may contain `null` for
  unset settings and still load. Rebuild any stores written with shortened
  system-tag names using the default full digests.
- `ContentHash.to_hex()` always returns the full digest. Slice the result for
  display when you need a shorter string.
