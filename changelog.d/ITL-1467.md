### Added

- `RunSummary.skipped_unbound_sources` maps each skipped node to the unbound source slots that blocked it.

### Fixed

- Load-only run summaries report nodes skipped for unbound sources, including when no node ran.
- Loading a saved job leaves missing Delta stores, source caches, and SQLite input database files absent. A local Delta store requires directories for the saved root and any saved scope.
- Saving a loaded job retains the recorded locations of stores that could not be opened.
- Load-only runs read existing source cache rows without writing to the cache. SQLite sources with literal filenames that start with `file:` keep that interpretation when restored.
