### Fixed

- A writable connector database no longer fails with `ArrowInvalid`
  when rows are queued for a table whose queued rows declare a column's nullability
  differently; the combined batch declares the column nullable. Where the
  stored column is `NOT NULL`, the second batch is refused when it is queued, with an error
  naming the column, and the rows queued before it are kept.
  Rows holding a null where their own schema declares a column or nested field non-nullable
  raise `NullInNonNullableColumnError` when they are queued, before anything is stored.
  If the connector rejects a flush, the attempted rows remain queued for retry.
  A read before the flush already combined stored and queued rows that differ that way.
  (ITL-1381)
