### Fixed

- A job runs an ordered operator given one stream for both inputs, `MergeJoin()(a, a)`
  and `SemiJoin()(a, a)` (ITL-1419, stage 1 of ITL-1472). A pipeline's graph edges now
  carry their input position, `(upstream, node, position)`: the argument index for an
  ordered pod, none for a commutative one. Both orchestrators give a node one input per
  edge, so the operator gets its two inputs, sync and async, in a job made from a
  `Pipeline` or a `PipelineJob`, after `PipelineJob.load` and through `node.run()`; before,
  the run raised "BinaryOperator requires exactly two input streams". No hash, stored path,
  stored column or saved file changes: a saved file still lists each `(upstream, node)`
  pair once, and the positions are rebuilt from an operator's saved `inputs` list.
  `Join`, `Rejoin` and a function pod given one stream twice are still refused (overlapping
  data columns).

### Known limitations

- `diagram()` draws one line for the two inputs of `MergeJoin()(a, a)`: drawing one line
  per positioned edge is left to stage 2 of ITL-1472.
