### Changed

- **Faster CI rounds** — CI runs the tests in parallel on every core of the runner
  (pytest-xdist, a new development dependency), turned on by `tests/conftest.py` when `CI` is
  `true` and no `-n` is given; local runs stay serial (`uv run pytest -n 4 tests/` runs them
  in parallel). A pull request runs the coverage job (`run-tests.yml`) once, on Python 3.13
  with `COVERAGE_CORE=sysmon`; a push to `main` runs it on Python 3.11, 3.12 and 3.13. The
  lint and type check workflow (`lint.yml`) now runs on the development repository too. The
  Release workflow's tests run in parallel. (ITL-1181)

### Fixed

- **Interrupt tests in a background process** — the tests in
  `tests/test_pipeline/test_job_run_in_event_loop.py` that press the notebook's interrupt
  button (`_thread.interrupt_main`) install Python's default SIGINT handler for their
  duration, so they pass in a process that ignores SIGINT (one started in the background).
  (ITL-1181)
