### Added

- `stream.explain()` says, for every source a stream reads, what the source applies itself
  (its `where` restriction and limit) and which steps drop rows after the rows are read
  (ITL-1402): a `filter` over an unrestricted table is shown to read the whole table. It
  computes, reads, polls and writes nothing and runs no user code. It returns an
  `Explanation` (`orcapod.types`), plain data whose `text()` lists one block per source;
  sources, conditions and argument items appear in no given order. Joins' unmatched rows,
  `SemiJoin`, `DropNulls`, `PolarsFilter`, a `Batch` dropping its last partial batch and a
  `Pick` or `Index` dropping a miss are listed too. The preview of a `filter` directly over
  a source shows the same split in one line.
