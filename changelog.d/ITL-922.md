### Breaking changes and migration

- Rebuilding rows with a `set[T]` of user-class values can change their hashes
  (ITL-922). The elements now sort by their stored fields in declared order.
  For example, a numeric field with `2` sorts before `10`. Orcapod recomputes
  cached results whose input hashes change when the data is rebuilt.

### Fixed

- Sets of user-defined logical types are ordered after Arrow coerces each element
  to the declared storage type (ITL-922). The sort descends into nested structs
  and lists, with `None` first. A NaN at any depth, incomparable values, or two
  elements with equal storage raise `CanonicalOrderError` naming the column.
