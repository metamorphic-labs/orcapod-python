### Fixed

- A `set[T]` of a logical type whose storage value is a scalar (text, bytes, a number) is
  stored in the same canonical order as a set of a plain type (ITL-922). A NaN, two
  elements with one storage value and elements that cannot be ordered are refused with
  `CanonicalOrderError`; before, a set of a user-registered logical type stored as a float
  and holding a NaN was stored, and hashed, in iteration order. The stored order of sets of
  `Path`, `UPath`, `UUID`, `File` and `Directory` is unchanged. A set of a user class (stored
  as a struct) is left as it was.
