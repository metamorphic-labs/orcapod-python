### Breaking changes and migration

- `PipelineJob` takes its database as `database`, not `store`: `PipelineJob(name=..., database=db)`, `PipelineJob.from_pipeline(..., database=db)`, `job.bind(database=db)`, `PipelineJob.load(path, database=db)` and the `job.database` property. There is no `store` alias. Migrate with `store=` to `database=` on those calls and `job.store` to `job.database`. The saved job file format is unchanged.
