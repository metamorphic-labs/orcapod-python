### Changed

- Async function pods now default to the usable CPU count clamped to 1–16 in-flight
  calls. A pod inherits the pipeline setting unless it supplies a positive integer or
  explicit `None`.

### Breaking changes and migration

- To keep unlimited async dispatch, use `PodConfig(max_concurrency=None)`. To inherit
  the pipeline limit, omit `max_concurrency` or set it to `"inherit"`.
