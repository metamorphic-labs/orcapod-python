### Changed

- The preview tells a plain tag from a data-tag (ITL-1304). A data-tag (one column that is
  both a tag and the data column of the same name) is still shown once, among the tags, in
  tag order, but with its own mark: in the notebook (HTML) preview its header is bold and
  underlined in the accent colour (a plain tag's stays bold), and in the text preview its name
  starts with `+` (a plain tag's with `*`). The legend line names exactly the marks shown:
  "bold = tag; bold underlined = data-tag (a tag that is also data)" in a notebook,
  "* = tag; + = data-tag (tag and data)" as text, each part only when such a column is
  shown. It holds for every view: `head()`, `tail()`, `sort_by_tags()`, `run()`, the
  notebook preview and the text form, of a source, a stream, an operator or function pod
  result and a job node, loaded jobs included. A `StreamView` has a new field,
  `data_tag_columns`, taken from the stream's `keys()`. Only the display is marked: the
  view's `table`, `as_table()`, the data frames and every schema, hash and stored form are
  unchanged.
