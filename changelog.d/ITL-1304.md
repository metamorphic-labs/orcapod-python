### Changed

- The preview tells a plain tag from a data-tag (ITL-1304). A data-tag (one column that is
  both a tag and the data column of the same name) is still shown once, among the tags, in
  tag order, but with its own mark. In the notebook (HTML) preview the marks compose
  (developer, November 21, 2026): a tag's header is bold in the accent colour (as before),
  a data column's header is now underlined (at normal weight), and a data-tag's header has
  both. The hidden column groups keep their look when shown: system tags are marked as
  tags, as before; source-info, context and content-hash columns stay unmarked. In the text preview a data-tag's name starts with `+` (a plain
  tag's with `*`; data columns stay unmarked). The legend line names exactly the marks
  shown: "bold = tag; underlined = data; bold underlined = data-tag (a tag that is also
  data)" in a notebook, "* = tag; + = data-tag (tag and data)" as text, each part only when
  such a column is shown. It holds for every view: `head()`, `tail()`, `sort_by_tags()`,
  `run()`, the notebook preview and the text form, of a source, a stream, an operator or
  function pod result and a job node, loaded jobs included. A `StreamView` has two new
  fields, `data_tag_columns` and `data_columns`, taken from the stream's `keys()`. Only the
  display is marked: the view's `table`, `as_table()`, the data frames and every schema,
  hash and stored form are unchanged.
