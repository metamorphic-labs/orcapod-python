### Changed

- **Faster job runs into `DeltaTableDatabase`.** An append commit now loads its table once and reads only the data files it added, instead of rebuilding the whole table's dataset (deltalake's own append cost still grows with the number of files). A lookup no longer walks every stored row. A table that does not exist yet is not reopened on every lookup. Stored rows, hashes, paths and table properties are unchanged. A table that another process creates during a run is seen from this database's next commit, as rows another process appends to an already-loaded table are. (ITL-1173)
