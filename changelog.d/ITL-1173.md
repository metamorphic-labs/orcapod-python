### Changed

- **Faster job runs into `DeltaTableDatabase`.** A commit now loads its table once and reads only the data files it added, so its cost no longer grows with the files already stored. A lookup no longer walks every stored row. A table that does not exist yet is not reopened on every lookup. Stored rows, hashes, paths and table properties are unchanged. A table that another process creates during a run is seen from this database's next commit, as rows another process appends to an already-loaded table are. (ITL-1173)
