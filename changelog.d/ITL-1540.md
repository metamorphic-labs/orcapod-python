### Fixed

- Status and logging observers now raise `SpiralDBObserverNotSupportedError` at setup when
  given a SpiralDB store, including scoped views and extension-aware wrappers (ITL-1540).

### Known limitations

- The observer setup check is a stopgap for ITL-1540. A new standalone SpiralDB database
  class or database wrapper requires a manual update to the check. ITL-1539 will decide
  the backing-store property every database should declare and wrappers should forward.
- When loading a composite observer from config, a refused child prevents log capture
  from being installed. An earlier child's database may already have been constructed,
  for example by creating a local Delta directory.
