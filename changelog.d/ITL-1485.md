### Changed

- A `SpiralDBTableSource` keeps the rows of its last preview (at most 10,000 rows and
  64 MiB). Showing it again, with fewer rows or other columns, makes no call to SpiralDB; it
  reads again only for more rows than it read, or after a source check (a job run or
  `check_for_new_data()`) moved the version it reads. A preview shows the version the source
  last checked, as before. `as_table()`, `as_df()` and `run()` still read the table every
  time.
