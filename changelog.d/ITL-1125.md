### Breaking changes and migration

- Assigning `upstreams` on an operator or function node now requires the same number
  of inputs. Where both schemas at a position are known without reading rows, the
  setter compares tags, data and system tags, including Arrow field types and
  nullability. Data meta columns do not enter the comparison. Assigning an unpolled
  source without a declared schema leaves its first fetch to normal data access.
  Build a new pipeline to change the number or known schemas of its inputs.
