### Breaking changes and migration

- Direct asynchronous `SemiJoin` calls must validate the exact ordered input pair
  with `validate_inputs(left, right)`. An unknown pair raises `InputValidationError`
  even when both channels have rows.
- Direct asynchronous `Index` and `Pick` calls on logical columns must call
  `validate_inputs(stream)` for the current input. The fallback type comes from
  that stream's schema and data context.

### Fixed

- Reusing a `SemiJoin`, `Index`, or `Pick` across streams now uses the matching keys
  or projected type for each input. Job projections also follow their current
  input schema after upstream rewiring.
