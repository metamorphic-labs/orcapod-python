### Breaking changes and migration

- A plain source over a job node's stored results now defaults to
  `derived_v1:<job path>:<hash label>:<node hash>` (ITL-1564). Pass an explicit
  `source_id` when a job name is unavailable or contains a separator.
- The full source id now enters the content hash of a plain derived source,
  including when you provide the name. Default source-cache paths and downstream
  pipeline-entry keys change. Run downstream jobs again to record results under
  the new keys. The origin job's stored results are still readable.
