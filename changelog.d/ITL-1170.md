### Changed

- The documentation is built as an [Astro Starlight](https://starlight.astro.build) site
  from `docs/`, with an API reference generated from the source code on every build. CI
  builds the site on every pull request and publishes it to GitHub Pages from `main` (on
  every push to `main`, or by hand); every page says that it documents the development
  version, not the latest release. mkdocs, mkdocs-material and mkdocstrings are no longer
  development dependencies; `griffelib` is. Building the site needs Node and pnpm
  (`site/README.md`). The site's address is configurable: `DOCS_SITE_URL` (origin) and
  `DOCS_SITE_BASE` (base path), from the environment or, in CI, the repository variables of
  the same names; unset or empty, it is `https://metamorphic-labs.github.io/orcapod-python/`.
  (ITL-1170)
- The documentation site takes the look of [orcapod.org](https://orcapod.org): the
  Orcapod logo in the header and as the favicon, the Asap and Lexend Exa fonts (bundled
  with the site), orcapod.org's background and text colours, and a blue accent for links, the
  sidebar, the banner and notes, in light and dark mode. The home page opens with the
  logo, a tagline and buttons to Getting Started, the tutorial and the repository.
  (ITL-1170)
