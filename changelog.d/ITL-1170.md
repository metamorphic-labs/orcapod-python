### Changed

- The documentation is built as an [Astro Starlight](https://starlight.astro.build) site
  from `docs/` and published to GitHub Pages at
  <https://nauticalab.github.io/orcapod-python/>. Its API reference is generated from the
  source code on every build. mkdocs, mkdocs-material and mkdocstrings are no longer
  development dependencies; `griffelib` is. Building the site needs Node and pnpm
  (`site/README.md`). (ITL-1170)
