### Changed

- The documentation is built as an [Astro Starlight](https://starlight.astro.build) site
  from `docs/`, with an API reference generated from the source code on every build. CI
  builds the site on every pull request; it is not published yet. mkdocs, mkdocs-material
  and mkdocstrings are no longer development dependencies; `griffelib` is. Building the site
  needs Node and pnpm (`site/README.md`). (ITL-1170)
