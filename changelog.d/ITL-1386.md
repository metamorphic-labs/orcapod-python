### Breaking changes and migration

- `add_record` and `add_records` now raise `ValueError` with the default
  `skip_duplicates=False` when a record ID is already stored or pending. A batch
  rejected for a duplicate queues no rows. Use `skip_duplicates=True` for
  write-if-missing behavior. If another writer commits an ID after the add-time
  check, the first commit keeps the row. (ITL-1386, ITL-1487)

### Fixed

- Appends reject mismatched field metadata inside Arrow extension storage, as
  they do for plain struct children. (ITL-1415)
- Delta excludes the record ID column from data-skipping statistics for every ID
  type so concurrent MERGEs detect conflicting writes. The statistics property
  is written at table creation. Tables created earlier keep their settings.
  (ITL-1444)
