### Breaking changes and migration

- Functions with several output keys must return an instance of the annotated
  container. If a function annotated with a tuple type currently returns a list,
  return a tuple with the values in `output_keys` order. Functions that declare
  several outputs through `output_schema` without a return annotation must also
  return a tuple (ITL-1254).

### Fixed

- A function pod that returns a dictionary for a tuple annotation raises
  `OutputContainerTypeError` before assigning any values. Previously, the pod
  could silently store the dictionary's keys as its outputs (ITL-1254).
