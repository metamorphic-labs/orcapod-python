### Changed

- The project's home is now `metamorphic-labs/orcapod-python`, and releases are cut there.
  The package's project URLs (homepage, repository, changelog, issues), the links in
  `README.md` and the tutorial's install and download commands point to it.
  `nauticalab/orcapod-python`, the release repository up to 0.3.0, is being retired. (ITL-1193)
- The library value types (`numpy.ndarray`, `torch.Tensor`, pandas and polars `DataFrame`
  and `Series`) stay provisional until the library value type audit, which comes after
  0.4.0rc1 rather than with 0.4; the documentation says so. (ITL-1193)
