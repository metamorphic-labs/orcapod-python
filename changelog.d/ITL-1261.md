### Fixed

- The execution log now records rejected function outputs as failures and includes the validation traceback when the executor supplies a traceback field. Lone surrogates in the traceback are escaped so the log can be stored as UTF-8 (ITL-1261).

### Known limitations

- If a custom executor records only `success=True` and `stdout_log` for a call that returns a string declared as `int`, its execution log records the failure and captured stdout without the validation reason. The job summary reports the original `OutputTypeError` (ITL-1261).
