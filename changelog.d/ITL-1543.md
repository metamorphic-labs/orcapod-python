### Breaking changes and migration

- Sources reject Arrow `null` fields at any depth, including in reserved columns.
  Declare a supported nullable column type for missing values.
- A custom system-tag column on a source must be a non-nullable string column
  with no null values. Convert custom tags to text before building the source.

### Fixed

- Join declares sorted system tags non-nullable when its inputs tie on pipeline
  hash. Existing entry IDs, instance IDs, record IDs and operator hashes stay the same.
