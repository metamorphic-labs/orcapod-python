### Changed

- **0.3.0 is withdrawn, and data context v1 is open until 0.4.0.** 0.3.0 was withdrawn on
  2026-11-17, before anyone used it, so that v1 of every hash freezes at 0.4.0 instead. The
  repository records the withdrawal: the 0.3.0 release revision left the v1 golden history,
  and the pins it shipped are kept under `withdrawn` in
  `src/orcapod/contexts/released_manifests.json`, with the date and the reason. A withdrawn
  version is never released again. No hash value changed. Until 0.4.0, a change to a v1 hash
  value is made only with the developer's approval of the exact list of entries that move,
  each explained; see *Withdrawing a release* in `docs/reference/golden-hashes.md`.
  (ITL-1255)
- **Install from the repository until 0.4.0.** No release after 0.1.4 is on PyPI, so a plain
  `uv add orcapod` installs 0.1.4; install the development version with
  `uv add git+https://github.com/metamorphic-labs/orcapod-python`. (ITL-1255)
