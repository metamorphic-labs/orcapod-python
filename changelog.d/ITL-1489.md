### Changed

- CSV sources now derive their default ID from `os.fspath(path)` when it differs from
  `str(path)`, so pass the previous `str(path)` value as `source_id` to keep using the old
  ID and cache.

### Fixed

- CSV, Delta and SQLite sources accept text path-like objects such as `pathlib.Path`.
  Jobs using these sources save the supplied path text as JSON strings. Delta sources
  pin local paths for reads and pass URI addresses through to deltalake.

### Known limitations

- A saved job loads relative source paths from its current working directory. If a
  relative path now points to a different dataset, reading the restored cached source
  mixes both datasets in the original cache (ITL-1546). Use absolute source paths
  when building a job you expect to load from a different working directory.
