### Changed

- **New Delta tables name their statistics columns.** A table that `DeltaTableDatabase` creates now sets the `delta.dataSkippingStatsColumns` table property to the columns deltalake can keep minimum and maximum statistics for (numbers, booleans, strings, dates, timestamps and decimals; never binary, list, map or struct columns), so writes to it no longer log `Skipping column ... because it's a binary field`. A table with no such column sets `delta.dataSkippingNumIndexedCols` to `0` instead. The property is set once, at creation: a column added later by schema evolution has no statistics. Existing tables are not altered and keep logging the line (see Troubleshooting for the `RUST_LOG` filter). Stored rows, hashes, paths and layouts are unchanged. (ITL-1187)
