### Changed

- **Function and side-effect job nodes work on their input's Arrow table** — on the sync
  path, a function job node takes each input row's entry id from slices of its input's
  table (the tag side with its system tags, and the hash of the data columns) instead of
  tables built from the row's values; shows its observers views of its input rows, made
  only when read; gives a stored result the id it was stored under by a shallow copy;
  and builds its output with the rows of stored results taken from the stored table. A
  side-effect job node hands on its input's table at the rows it passed on. Every
  output, stored row, entry id, observer event and error is as before. Third and fourth
  stages of the table transport between job nodes
  (`docs/dev/specs/itl-1347-job-table-transport.md`). (ITL-1361)
