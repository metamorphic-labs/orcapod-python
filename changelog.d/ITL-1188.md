### Added

- **Release workflow: `skip_tests` input** — the Release workflow (`release.yml`) takes a
  boolean `skip_tests` (default `false`) that skips its test jobs; branch validation, the
  license check, the build, the tag and publishing still run. Only the input skips the tests:
  a failed or cancelled test job still stops the release. A run with the tests skipped writes
  a warning and a run summary line naming who started it. It is an exception, for a commit
  whose required CI is already green on the development repository; see `RELEASING.md`,
  *Skipping the release tests*. (ITL-1188)
