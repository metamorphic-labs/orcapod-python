### Changed

- Documented implicit nullability for nested fields produced from Python declarations in data context v1. Explicit Arrow flags still distinguish schemas for joins and slot binding, and a refusal now names the differing nested field and explains how to match the flags.

### Fixed

- A function pod output declared as `set[T]` must be a `set` instance. Previously accepted non-set iterables, such as lists and `frozenset` instances, now raise an output type error even when their elements are valid. Set elements must match the declared element type. For example, `set[int]` rejects `None` as an element, while `set[int | None]` accepts it.
