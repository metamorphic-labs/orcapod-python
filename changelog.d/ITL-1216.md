### Breaking changes and migration

- **`Pipeline.show_graph()` and the Graphviz renderer are removed; Orcapod no longer depends on `graphviz` or `matplotlib`.** `Pipeline.show_graph()`, and `render_graph()`, `render_graph_dark_theme()`, `GraphRenderer` and `StyleRuleSets` in `orcapod.pipeline.graph`, are gone, with no replacement of the same name: calling `show_graph()` raises `AttributeError`. To see a pipeline, show the job (or the pipeline) at the end of a notebook cell, or call `job.diagram()`: `print(job.diagram())` lists the graph as text and `job.diagram().save("pipeline.html")` writes a page. The diagram needs no Graphviz `dot` program. Installing Orcapod no longer installs `graphviz` or `matplotlib` (nor `contourpy`, `cycler`, `fonttools`, `kiwisolver`, `pillow` and `pyparsing`, which came with `matplotlib`); code that relied on Orcapod to install either must now install it itself. (ITL-1216)
