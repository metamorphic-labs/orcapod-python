### Fixed

- A process that read stored rows holding a logical type (a path, a set, a dataclass or
  pydantic model, an array) could end, after all of its work, with `terminate called without
  an active exception` (exit code 134) on Linux with Python 3.11 or 3.12, or hang at exit.
  Orcapod keeps Arrow types built with `make_arrow_extension_type` and its ignore-list
  Arrow types alive through shutdown. (ITL-1422)
