### Added

- `stream.add_tags(cohort="A", run=3)` and the `AddTags` operator add tags that hold one
  constant value on every row, after the stream's tags; data columns, source info and system
  tags are unchanged. The tags are given as keyword arguments or as one dict. A value is a
  `bool`, `int`, `float`, `str` or `bytes`, typed `bool`, `int64`, `double`, `large_string` or
  `large_binary` and non-nullable; any other value, a name that is already a column, and a
  reserved name are refused. The names and values are the operator's identity. A function
  form, computing new tags from each row, is planned.

### Changed

- The operator / function pod boundary now reads: an operator never adds or synthesizes data,
  and may add a tag.
