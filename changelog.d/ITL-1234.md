### Changed

- `GroupBy` puts all rows whose key is NaN into one group (ITL-1234), as the joins match a
  NaN key; with several keys, the key tuples compare element by element with that rule.
  Before, each such row was a group of its own, and those groups came out in the input's
  row order. A NaN key sorts after every number and before null. Only an input with a NaN
  key changes: its groups, their member lists, folded ids and hashes.

### Fixed

- `GroupBy` emits a float key whose members differ in bits as the one with the smallest
  bit pattern at the column's own width (ITL-1234): `0.0` over `-0.0`, the canonical NaN
  over a NaN with another sign or payload. Before, `0.0` and `-0.0` were already one
  group, but the group emitted the key of the first row in input order, so its value and
  the row's hashes depended on the row order. A group whose members agree emits their
  value as before.
