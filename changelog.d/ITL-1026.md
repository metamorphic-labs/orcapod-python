### Added

- A saved job file and a saved pipeline file now carry `orcapod_version`, the value of `orcapod.__version__` of the release that wrote them, beside the format version (ITL-1026). It is informational: loading never reads it, and a file written before this change, without the field, loads as before. The format versions stay `0.1.0`; no hash, golden value or stored table changes.
