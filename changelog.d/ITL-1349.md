### Changed

- **Less overhead per row.** Orcapod imports pyarrow, `pyarrow.compute`, polars, numpy and pandas directly instead of through a lazy module wrapper, which cost a Python call on every attribute access (millions in one job run). `import orcapod` already loaded these modules, so import time does not change. Modules that `import orcapod` does not load (networkx, deltalake, the optional database clients) stay deferred. Results, hashes and stored tables are unchanged. (ITL-1349)
