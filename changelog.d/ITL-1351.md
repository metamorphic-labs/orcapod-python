### Changed

- A run counts the rows of the nodes it holds without building them (ITL-1351). The run
  summary's count of a held node's rows (`plan_run`) iterated the node's rows, which built
  a `(Tag, Data)` pair per row of an operator's output only to count it; a run in which
  every node holds a current run spent most of its time there. Each kind of job node that
  holds a run now counts what it holds (`held_row_count`: an operator node its output
  table's row count, a function node its run's inputs with an output, a side-effect node
  its held rows), with the same counts and summaries as before.
