### Fixed

- **`MapTags(drop_unmapped=True)` predicts the system-tag columns it keeps** — its
  predicted output schema (`output_schema(columns={"system_tags": True})`,
  `output_schema(all_info=True)`) left out the system-tag columns, which the computed table
  keeps, so the prediction and the rows disagreed. Every mapper (`MapTags`, `MapData`,
  `MapColumns`) now renames and drops only user columns, in its prediction as in its result;
  no row, column, hash or stored path changes. (ITL-1363)
