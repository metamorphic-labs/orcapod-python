### Added

- `SpiralDBTableSource(..., connector=<SpiralDBConnector>)`: sources of one project and
  dataset that are given one connector use its SDK client, so they sign in once and read the
  dataset's schema table once per version of it (ITL-1457). It is part of no identity, is not
  saved, and changes no row, order, hash or refusal; without it a source makes its own, as
  before.
