### Added

- `SpiralDBTableSource(..., connector=<SpiralDBConnector>)`: sources of one project and
  dataset that are given one connector use its SDK client, so they sign in once (ITL-1457).
  Only the client is shared: each source reads the dataset's schema table and makes every
  other call as before, so no row, order, hash or refusal changes. It is part of no identity
  and is not saved. Without the argument a source makes its own connector, as before.

### Fixed

- `SpiralDBConnector` copies the `overrides` it is given, and `to_config()` returns a copy, so
  changing either dictionary later cannot make it save or report another service address than
  the one it reads (ITL-1457).
