### Changed

- A SpiralDB source keeps the opened snapshot of its pinned version, so that reading it
  again does not fetch its schema and plan again (ITL-1457). Every read and check still opens
  the table by name and then checks the dataset's schema table before anything is scanned,
  and reads through the kept snapshot only when the name leads to that same id and version.
  Rows, order, hashes, refusals and warnings are unchanged.
