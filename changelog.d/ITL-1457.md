### Changed

- SpiralDB sources repeat fewer service calls (ITL-1457). The sources of one process that
  use one service address and one sign-in share an SDK client, and a dataset's schema table
  is read once for all of them while its version has not moved. Its version is still checked
  at every lookup that prepares a read, now at the same time as the table's own schema is
  fetched, and the checks of neighbouring SpiralDB sources before a run are made at the same
  time. Rows, order, hashes, refusals and warnings are unchanged. A changed environment or
  saved login, or a client whose call failed, gives a new source a new client; closing a
  source affects no other.
