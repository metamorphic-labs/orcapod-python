### Changed

- Python sources and datagrams issue a `ValueConversionWarning` when a Python `float` is supplied for a top-level column declared `numpy.float32` in a Python schema. Python shows the warning once per location by default. Pass `numpy.float32` values to control the conversion, or declare the column `float` to retain Python float precision. (ITL-924)

### Known limitations

- A `ListSource` that reuses an Arrow-backed float32 tag passes its values on as Python floats and can warn even when the stored values are already representable as float32. Float32 positions inside a list, dict value, or struct do not warn. Conversions driven by an Arrow schema can also narrow silently, including updates to materialized datagrams. Refusal of float32 and float16 dict key and set element types is tracked in ITL-1591.
