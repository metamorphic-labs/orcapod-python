### Changed

- Orcapod issues one `ValueConversionWarning` per process when a Python `float` is supplied for a column declared `numpy.float32` in a Python schema. Values that float32 cannot hold exactly are stored changed. Pass `numpy.float32` values to control the conversion, or declare the column `float` to retain Python float precision. (ITL-924)

### Known limitations

- Plain Python floats can still narrow silently under an Arrow float32 schema, including when updating a materialized datagram. Refusal of float32 and float16 dict key and set element types is tracked in ITL-1591.
