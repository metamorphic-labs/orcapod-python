### Changed

- The record a function result row keeps about its function (`python.function.v1`,
  `rev1`; ITL-1256): a new column `function_module` (the function's `__module__`);
  `function_signature_hash` is now the hash of the declared interface (each input with its
  effective type and default, by name; the outputs with their types in declared order;
  label `function_signature_v1`), so two pods whose output keys differ only in order record
  different values; `function_content_hash` is the hash of the source text from the `def`
  line on, decorator lines excluded (label `function_content_v1`), and is null when the
  source cannot be read (a function typed into a plain REPL or made with `exec`). See
  `docs/reference/data-function-types.md`.
