# ITL-1489 — Save jobs built from path-like sources

1. Reproduce the CSV job save error on `main` and cover text conversion and source identity
   for CSV, Delta and SQLite.
2. Convert the input once at construction with `os.fspath`. Use the path text as passed
   for saved paths and default source names. Pin local access paths at construction by
   joining the working directory without resolving symlinks or `..`. Give Delta URIs
   directly to deltalake. Stack on PR #581 for SQLite read-only restoration and preserving
   unavailable source bindings when re-saving jobs.
3. Verify the source tests, lint, format, type checking and golden hashes. Update docs
   examples if the pending tutorial PR has merged.

The developer confirmed on November 27, 2026, that the filesystem path determines
the default source ID. A CSV path object with `str(path) == "display.csv"` and
`os.fspath(path) == "data/entries.csv"` now defaults to `csv_v1:data/entries.csv`,
which names the file the source actually opens.
