## `src/orcapod/semantic_types/universal_converter.py` — Python-to-Arrow conversion

### FN32 — Python floats were narrowed silently into a float32 column
**Status:** resolved
**Severity:** high
**Issue:** ITL-924

Arrow narrows a Python `float` supplied for a column declared `numpy.float32`.
For example, `1e-50` becomes `0.0` and `0.1` becomes `0.10000000149011612`.

**Fix:** Issue one `ValueConversionWarning` per process for Python float inputs
under a Python float32 declaration. The warning uses the input type in the
existing converter traversal. Arrow still receives the original value. Forked
children start with fresh warning state. An ignored warning leaves the first
visible warning available, and active error filters still apply. ListSource
carries stored Tag provenance through row conversion so reusing Arrow float32
tags keeps the same acceptance and storage as before.

**Known limitations:** Plain-value conversions driven by an Arrow schema can
still narrow silently, including materialized datagram updates. ITL-1591
tracks refusal of float32 and float16 dict key and set element types.
