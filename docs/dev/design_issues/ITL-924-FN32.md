## `src/orcapod/semantic_types/float_narrowing.py` — Python-to-Arrow conversion

### FN32 — Python floats were narrowed silently into a float32 column
**Status:** resolved
**Severity:** high
**Issue:** ITL-924

Arrow narrows a Python `float` supplied for a column declared `numpy.float32`.
For example, `1e-50` becomes `0.0` and `0.1` becomes `0.10000000149011612`.

**Fix:** Issue a standard `ValueConversionWarning` when a Python source or
datagram receives a Python float for a top-level column declared
`numpy.float32` in a Python schema. Python shows it once per location by
default. Arrow receives the original value.

**Known limitations:** Float32 positions nested in lists, dict values, or
structs and conversions driven by an Arrow schema can narrow silently.
`ListSource` passes values from reused Arrow-backed float32 tags on as Python
floats, so they can also warn. ITL-1591 tracks refusal of float32 and float16
dict key and set element types.
