## `src/orcapod/core/data_function.py` — returned values not checked against the declared type

### OC1 — Multiple outputs were unpacked from the wrong return container
**Status:** resolved
**Severity:** critical
**Issue:** ITL-1254

When a function declared several outputs, the parser iterated any returned
iterable. A dictionary returned for a tuple annotation yielded its keys, which
could be stored silently when the declared output types were strings.

**Fix:** The output parser checks the returned container against the annotation
before unpacking. Functions that declare several outputs through `output_schema`
without a return annotation must return a tuple. A mismatch raises
`OutputContainerTypeError` with the function name, the returned type and the remedy.
