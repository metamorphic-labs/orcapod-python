## `src/orcapod/core/streams/`

### AS2 — A stream's Arrow table and its rows can disagree about column types
**Status:** in progress
**Severity:** high
**Issue:** ITL-1543

The stream defines the Arrow schema of each row. Today a row can rebuild its
columns in a different form, which makes identity and storage depend on how the
data was read. For example, a Join of streams tied on pipeline hash can declare
its sorted system tags nullable, although its rows have non-nullable system tags.

Part A corrects that Join schema and rejects Arrow Null in sources, including
nested Null. Part B carries a stream's system-tag fields through row and batch
reads, including the standalone async Join. Source-info flag decisions remain
open in ITL-1557, and the existing row-built guard remains pending PR 601.
