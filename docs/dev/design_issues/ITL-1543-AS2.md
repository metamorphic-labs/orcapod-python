## `src/orcapod/core/streams/`

### AS2 — A stream's Arrow table and its rows can disagree about column types
**Status:** resolved
**Severity:** high
**Issue:** ITL-1543

The stream defines the Arrow schema of each row. A row that rebuilds its
columns in a different form can make identity and storage depend on how the
data was read. For example, a Join of streams tied on pipeline hash could
declare its sorted system tags nullable while its rows used required fields.

**Fix:**

Part A corrected the Join schema and rejected Arrow Null in sources, including
nested Null. Part B carries declared system-tag fields through rows, tables and
batches, including standalone async joins and both Join and MergeJoin kernels.
Operators with an Arrow output declaration check the materialized fields before
writing cache rows. ITL-1557 makes every top-level source-info field nullable and
ITL-1491 carries the pipeline's declared token types through transport. ITL-1534
tracks hand-built rows passed directly from a held node on the async route.
