## `src/orcapod/core/operators/drop_nulls.py` — held row context keys

### DN2 — DropNulls replaced the context keys held by surviving rows
**Status:** resolved
**Severity:** high
**Issue:** ITL-1385

A raw Arrow table stream can hold a separate data context key for each row.
`DropNulls` read the table without its context column, so its result reported the
default key for every surviving row when exported as an Arrow table.

**Fix:** Include the context column in the input to the shared Arrow narrowing rule.
The row mask carries each surviving key alongside its system tags and source info.
The async operator preserves the context of each datagram it receives. Rows yielded
from a mixed-context Arrow table still report the stream's one context (ITL-1359).
