## `src/orcapod/core/nodes/operator_node.py`

### OC1 — Operator cache token fields depend on the write's values
**Status:** resolved
**Severity:** high
**Issue:** ITL-1562

An operator cache used required token fields for null-free writes and nullable
fields for writes with missing tokens. Appending the other schema could fail or
store a key that could not be reproduced under the table's held schema.

**Fix:** Keep the output stream's declared fields through the operator output
keeper and hash rows under those fields. Store the records under `odb_v3` and
report `odb_v2` tables through the existing stale-layout accounting.
