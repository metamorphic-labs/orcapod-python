## `src/orcapod/databases/`

### WK1 — A strict add accepts an already stored record ID
**Status:** resolved
**Severity:** high
**Issue:** ITL-1386

A strict add of an already stored ID was silently skipped by Delta and silently
replaced the row in memory and connector-backed stores. All three refused an ID
that was already in the pending batch.

**Fix:** Check stored IDs when adding, along with the pending IDs, and reject the
entire add if any conflict. The write-if-missing option still skips duplicates.
