## `src/orcapod/databases/connector_arrow_database.py`

### WK2 — A second connector commit replaces the first writer's row
**Status:** resolved
**Severity:** high
**Issue:** ITL-1487

Two connector-backed database handles could queue the same new ID, then commit
different values. The last flush replaced the first writer's row when adding
with the default duplicate policy.

**Fix:** Use the connector's insert-if-missing operation at commit in both modes.
A conflicting ID visible at add time is refused in strict mode.
