### CA4 — Distinct paths could share a SQL record table
**Status:** resolved
**Severity:** critical
**Issue:** ITL-1552

Path sanitization could turn distinct paths into the same table name and let one
write overwrite the other's rows. PostgreSQL also refused names beyond 63 bytes.

**Fix:** Both SQL backends use a 63-byte budget for the path hint and digest. A
versioned catalog keeps the original paths so lookups can refuse name collisions.
