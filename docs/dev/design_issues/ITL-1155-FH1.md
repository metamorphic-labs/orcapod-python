## Hash labels — file content hashes (ITL-1155)

### FH1 — File hashing exposed algorithms outside the hash label rule
**Status:** resolved
**Severity:** high
**Issue:** ITL-1155

File hashing accepted several digest names as labels, plus `hash_path`, which
hashed the path string. A file content hash label needs to identify the full
procedure that produced it.

**Fix:** Use SHA-256 over the file bytes and keep the `sha256` label. Reject
other algorithms in built-in and custom file hashers and cache writes. Verify
computed file hashes before returning, caching, or folding them into a directory
hash. Cache reads for other labels miss, and clearing a persistent cache
preserves historical rows. Remove the algorithm selection from cache warming and
drop the `xxhash` dependency.
