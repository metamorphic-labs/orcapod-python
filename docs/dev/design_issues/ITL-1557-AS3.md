## `src/orcapod/core/streams/`

### AS3 — Token fields disagree between streams and rows
**Status:** resolved
**Severity:** high
**Issue:** ITL-1557

Sources declared generated source-info fields non-nullable while the rows read
from those streams declared them nullable. A bare stream and a CachedSource
incorporated the stream field into their hashes, while a function node used the
row field for its instance ID.

**Fix:** Declare every source-info field nullable at the top level in
`arrow_utils.source_info_field`. Write CachedSource fields and record hashes
under `sdb_v2` and report older tables through stale-table accounting. Function
entry and instance IDs are preserved. Operator caches follow the output stream's
declared fields under ITL-1562.
