## `src/orcapod/core/operators/merge_join.py` — Arrow types

### MJ5 — `MergeJoin` raised `TypeError` when a colliding data column held a null
**Status:** resolved
**Severity:** high
**Issue:** ITL-1243 (related: ITL-1281)

`MergeJoin` sorted each row's merged values as Python values, so a null beside a value (or
two nulls) raised `TypeError: '<' not supported between instances of ...`, and a run over
any nullable colliding column holding a null failed.

**Fix:** resolved by ITL-1281 (MJ3): nothing is compared. A null is merged like any value,
in argument order: the merged column is `large_list<T>`, never null itself, and its element
is null where the input's value is.
