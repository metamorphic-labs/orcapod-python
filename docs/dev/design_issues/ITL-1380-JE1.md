## `src/orcapod/core/operators/` — join type checking

### JE1 — Joins accepted keys with different logical type identifiers
**Status:** resolved
**Severity:** critical
**Issue:** ITL-1380

PyArrow can consider two instances of one extension type class equal even when they
serialize different parameters. This allowed shared tag keys with different logical
type identifiers to match and allowed incompatible colliding columns past MergeJoin's
type check.

**Fix:** Shared Arrow types must agree after large normalization and carry the same full
extension identifiers throughout the type, including nested children. Join errors name
the column and show the identifiers that each input provided.
