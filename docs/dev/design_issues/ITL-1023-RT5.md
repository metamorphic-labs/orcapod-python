## `src/orcapod/core/data_tags.py` — data-tags workshop slice (ITL-1023)

### RT5 — Join raises when one side's list-valued key has one source-info token per member and the other one per cell
**Status:** open
**Severity:** medium
**Issue:** ITL-1201 (found on ITL-1023, PR #342)

`Batch` over a data-tag key gives a list with one source-info token per member; a source whose declared tag holds a list value gives one token per cell. `Join` on that key merges the two (`merge_source_info`) and raises `ValueError: cannot merge the source info of a list with that of a scalar` on every matched row, although the key values and types agree. Reproduced with `Join()(Batch(batch_size=2)(a), b)` where `a` has scalar `k` and `b` has `k=[1, 2]`. The source-info shape of a list-valued key declared by a source has to be decided (or the join refused up front, naming the column and both shapes). ITL-1201.
