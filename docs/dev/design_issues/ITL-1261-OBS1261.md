## `src/orcapod/core/data_function.py` — function output validation

### OBS1261 — The execution log recorded success for rejected output
**Status:** resolved
**Severity:** medium
**Issue:** ITL-1261

Executors recorded a successful function return before the data function checked
the output's shape and type. A job then counted the row as failed while the
execution log still reported success with no traceback.

**Fix:** Defer successful execution records until output validation finishes.
If validation raises, record the failure with the captured I/O and fill the
traceback field when the executor supplies one. Escape lone surrogates in the
traceback so the log can be stored as UTF-8.
