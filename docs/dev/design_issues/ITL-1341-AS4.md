## `src/orcapod/core/streams/`

### AS4 — Arrow streams accepted invalid system tags
**Status:** resolved
**Severity:** medium
**Issue:** ITL-1341

A raw `ArrowTableStream` accepted non-string system tags, null system-tag values,
and incomplete source-id/record-id pairs. These columns could propagate through
operators even though they could not represent a complete provenance ID.

**Fix:** Validate system tags at construction, including columns nominated
through `system_tag_columns`. Require string values without nulls and check that
every source-id or record-id column has its partner at the same provenance path.
Keep the declared field nullability and support custom string system tags.
