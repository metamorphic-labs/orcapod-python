## `src/orcapod/core/nodes/function_node.py`

### RT7 — Observers of a fall-through node see only the function's columns on the async compute path
**Status:** open
**Severity:** low
**Issue:** ITL-1203 (found on ITL-1023, PR #342)

For a function node whose pod lets a data-tag `t` fall through, `on_data_start` / `on_data_end` receive the node's full input and output (`t` included) on the sync path and on cache hits, but on the async compute path only the function's input and output (without `t`): the channel path forwards the projected input and the plain output through `_NodeLabelObserver`. An observer that reads `t` fails, or records different rows, on that path only. Reproduced (ITL-1203 holds the script). Reported by CodeRabbit on PR #342.
