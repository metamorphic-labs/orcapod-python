## `src/orcapod/databases/delta_statistics.py`

### WK4 — Delta file statistics on typed record IDs can let concurrent commits miss an overlap
**Status:** resolved
**Severity:** high
**Issue:** ITL-1444

Statistics on non-binary record IDs could let Delta file skipping hide a conflict
when two handles committed the same new ID.

**Fix:** Exclude the record ID from every new table's statistics configuration.
Existing table properties are retained.
