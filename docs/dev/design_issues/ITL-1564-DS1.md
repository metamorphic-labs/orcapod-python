## `src/orcapod/core/sources/`

### DS1 — Plain derived source IDs omit the origin job
**Status:** resolved
**Severity:** medium
**Issue:** ITL-1564

Two jobs with different names can store equal-hash nodes whose derived sources share
an ID, even though the jobs store their rows separately.

**Fix:** Use the job name and labelled node content hash in a plain derived source's
default ID. Use the root source content identity, which includes the full ID and Arrow
schema identity. The origin's stored tables keep their provenance. Plain reads expose no
system tags and return null source-info tokens.
